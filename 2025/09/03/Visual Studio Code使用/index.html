Visual Studio Code使用说明

使用方法

安装 VS Code

  1. 访问 VS Code 官方网站。
  2. 根据自己的操作系统选择合适的安装包进行下载。
  3. 运行安装程序，按照提示完成安装。

安装 Python 扩展

  1. 打开 VS Code。
  2. 点击左侧侧边栏中的扩展图标（四个方块）。
  3. 在搜索框中输入 “Python”。
  4. 选择 “Python” 扩展并点击安装按钮。

创建和打开 Python 项目

  1. 创建一个新的文件夹作为项目目录。
  2. 打开 VS Code，点击 “文件” -> “打开文件夹”，选择刚刚创建的项目目录。

配置 Python 解释器

  1. 打开 VS Code 中的 Python 文件。
  2. 点击右下角的 Python 解释器版本号。
  3. 在弹出的列表中选择合适的 Python 解释器。

常见实践

代码调试

  1. 在代码中设置断点，点击行号旁边的空白处。
  2. 按下 F5 启动调试。
  3. 使用调试面板中的按钮（继续、单步跳过、单步进入等）进行调试。

代码格式化

  1. 安装 “Python” 扩展后，VS Code 会自动支持代码格式化。
  2. 按下 Shift + Alt + F 格式化当前文件的代码。

代码自动完成

VS Code 的 Python 扩展提供了智能代码补全功能，当你输入代码时，会自动提示可能的代码片段和方法。

版本控制

  1. 安装 “Git” 扩展。
  2. 在项目目录中初始化 Git 仓库，使用命令 git init。
  3. 使用 VS Code 中的源代码管理面板进行代码提交、推送等操作。
